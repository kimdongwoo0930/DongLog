## 📌 집계 함수란?

집계 함수(Aggregate Function)는 **여러 행의 데이터를 하나의 값으로 계산**해주는 함수입니다.

| 함수 | 설명 |
|------|------|
| `COUNT()` | 행의 개수를 셉니다 |
| `SUM()` | 합계를 계산합니다 |
| `AVG()` | 평균을 계산합니다 |
| `MAX()` | 최댓값을 반환합니다 |
| `MIN()` | 최솟값을 반환합니다 |

---

## 1️⃣ COUNT — 개수 세기

가장 자주 쓰이는 함수입니다. **전체 회원 수**를 구해봅시다.

```sql
SELECT COUNT(*) FROM members;
```

```
+----------+
| COUNT(*) |
+----------+
|       30 |
+----------+
```

`COUNT(*)`는 NULL 값을 포함한 **모든 행**을 셉니다.
특정 컬럼의 NULL을 제외하고 세고 싶으면 `COUNT(컬럼명)`을 씁니다.

```sql
-- 이메일이 등록된 회원 수 (NULL 제외)
SELECT COUNT(email) FROM members;
```

> 💡 **코테 TIP**: `COUNT(*)`와 `COUNT(컬럼명)`의 차이를 묻는 문제가 종종 나옵니다.
> `COUNT(*)`는 NULL 포함, `COUNT(컬럼명)`은 NULL 제외!

---

## 2️⃣ SUM — 합계 구하기

**전체 주문 금액의 합계**를 구해봅시다.

```sql
SELECT SUM(price) AS 총_주문금액
FROM orders;
```

```
+--------------+
| 총_주문금액   |
+--------------+
|     22760000 |
+--------------+
```

총 주문 금액이 약 **2,276만 원**이네요!

WHERE와 함께 쓰면 조건부 합계도 가능합니다.

```sql
-- 2024년 3월 이후 주문 금액 합계
SELECT SUM(price) AS 3월이후_주문금액
FROM orders
WHERE order_date >= '2024-03-01';
```

> 💡 **코테 TIP**: SUM은 NULL을 자동으로 무시합니다. NULL + 숫자 = NULL이 아니라, NULL은 그냥 건너뜁니다.

---

## 3️⃣ AVG — 평균 구하기

**회원들의 평균 나이**를 구해봅시다.

```sql
SELECT ROUND(AVG(age), 1) AS 평균_나이
FROM members;
```

```
+-----------+
| 평균_나이  |
+-----------+
|      29.1 |
+-----------+
```

`ROUND(값, 소수점자리수)`를 함께 쓰면 깔끔하게 출력됩니다.

주문 금액의 평균도 구할 수 있습니다.

```sql
-- 1인당 평균 주문 금액
SELECT ROUND(AVG(price), 0) AS 평균_주문금액
FROM orders;
```

---

## 4️⃣ MAX — 최댓값 구하기

**가장 비싼 주문 금액**을 구해봅시다.

```sql
SELECT MAX(price) AS 최고_주문금액
FROM orders;
```

```
+---------------+
| 최고_주문금액  |
+---------------+
|       2500000 |
+---------------+
```

250만 원! MacBook Pro 또는 RTX 4090 중 하나겠네요.

날짜에도 사용할 수 있습니다.

```sql
-- 가장 최근 주문 날짜
SELECT MAX(order_date) AS 최근_주문일
FROM orders;
```

```
+-------------+
| 최근_주문일  |
+-------------+
| 2024-04-02  |
+-------------+
```

---

## 5️⃣ MIN — 최솟값 구하기

**가장 저렴한 주문 금액**을 구해봅시다.

```sql
SELECT MIN(price) AS 최저_주문금액
FROM orders;
```

```
+---------------+
| 최저_주문금액  |
+---------------+
|         15000 |
+---------------+
```

충전 케이블이나 랜선 같은 소품이겠네요.

가장 어린 회원도 찾을 수 있습니다.

```sql
SELECT MIN(age) AS 최연소_나이
FROM members;
```

## 6️⃣ 여러 집계 함수 한 번에 쓰기

여러 집계 함수를 **한 쿼리에서 동시에** 사용할 수 있습니다.

```sql
SELECT
    COUNT(*)               AS 총_주문수,
    SUM(price)             AS 총_주문금액,
    ROUND(AVG(price), 0)   AS 평균_주문금액,
    MAX(price)             AS 최고_주문금액,
    MIN(price)             AS 최저_주문금액
FROM orders;
```

```
+-----------+--------------+---------------+---------------+---------------+
| 총_주문수  | 총_주문금액   | 평균_주문금액  | 최고_주문금액  | 최저_주문금액  |
+-----------+--------------+---------------+---------------+---------------+
|        80 |     22760000 |        284500 |       2500000 |         15000 |
+-----------+--------------+---------------+---------------+---------------+
```

한 번의 쿼리로 핵심 통계를 모두 뽑을 수 있습니다.

---

## 7️⃣ WHERE + 집계 함수 조합

조건을 걸고 집계할 때는 **WHERE를 집계 함수보다 먼저** 씁니다.

```sql
-- 100,000원 이상인 주문들의 통계
SELECT
    COUNT(*)             AS 고가_주문수,
    SUM(price)           AS 합계,
    MAX(price)           AS 최고가,
    MIN(price)           AS 최저가
FROM orders
WHERE price >= 100000;
```

> ⚠️ **주의**: WHERE 절에는 집계 함수를 직접 쓸 수 없습니다.
> `WHERE SUM(price) > 100000` ← 이렇게 쓰면 에러!
> 집계 결과에 조건을 걸고 싶다면 다음 편에서 다룰 `HAVING`을 사용해야 합니다.

## 📝 핵심 정리

| 함수 | 사용 예 | 기억할 것 |
|------|---------|----------|
| `COUNT(*)` | 전체 행 수 | NULL 포함 |
| `COUNT(컬럼)` | NULL 제외 행 수 | NULL 제외 |
| `SUM(price)` | 금액 합계 | NULL 자동 무시 |
| `AVG(price)` | 금액 평균 | ROUND와 자주 함께 사용 |
| `MAX(price)` | 최고 금액 | 날짜에도 사용 가능 |
| `MIN(price)` | 최저 금액 | 날짜에도 사용 가능 |
